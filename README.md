# 🎮 Rock Paper Scissors — Interactive Web Game

A sleek, responsive, and feature-packed **Rock Paper Scissors** game built using **HTML5, CSS3, and modern JavaScript**. Featuring a modern dark mode interface with neon accent lighting and complete score persistence.

---

## 🌟 Features & Highlights

* **🎯 Interactive Welcome Screen:** A dedicated landing screen ("Excited!! To play Rock Paper Scissors") with a smooth start trigger.
* **💡 Glowing Dark Theme UI:** Stylish dark background with glowing yellow icons and custom button feedback.
* **📊 Comprehensive Score Tracking:**
  * Real-time tracking for **Wins**, **Losses**, and **Ties**.
  * Dynamic calculation of **Total Matches Played**.
* **⚔️ Live Match Visualizer:** Displays the player's pick versus the computer's choice with immediate result outcome announcements (*"You Win!"*, *"You Lose"*, or *"It's a Tie"*).
* **🔄 Quick Reset:** Instant score reset feature to restart game stats clean.

---

## 🛠️ Tech Stack & Implementation Details

* **HTML5 :** Structured semantic layout separating the landing view and primary game panel.
* **CSS3 :** Custom styling featuring CSS flexbox layout, dark aesthetics, box-shadow glow effects, and responsive alignments.
* **JavaScript :**
  * Random choice generation algorithm for the computer player.
  * Conditional game logic comparing moves.
  * Dynamic DOM manipulation for instant score updates without page reloads.

---

## 🕹️ How to Play

1. Click **Play** on the welcome screen to launch the game interface.
2. Select your hand gesture: **Rock** ✊, **Paper** ✋, or **Scissors** ✌️.
3. Watch the computer generate its move instantly and review your live match results at the top!
